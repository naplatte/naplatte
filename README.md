## About

Hi, I'm **Hao Cui**, a graduate student from China focused on software engineering and AI research.

**C++ is my primary development focus.** I also work with **Go backend systems** and use **Python** for research, tooling, and LLM applications.

My research interest is **social bot detection**, especially graph-based methods for understanding user behavior, social relations, and multi-source signals.

- **Core engineering:** C++, Linux, concurrent programming, and reusable software components.
- **Backend practice:** Go, Gin, GORM, MySQL, Redis, and RabbitMQ.
- **AI engineering:** RAG, agents, MCP, skills, and workflow automation.
- **How I learn:** build small projects, read papers, and turn ideas into runnable code.
